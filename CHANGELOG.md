# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2024-01-01

### Added
- Complete REST API with FastAPI
- Real-time WebSocket support
- ICA-based artifact separation
- Machine learning artifact detection (Random Forest, SVM)
- Deep learning autoencoder support
- Docker containerization
- Prometheus + Grafana monitoring
- CI/CD pipeline with GitHub Actions
- Comprehensive test suite
- API documentation with Swagger/OpenAPI

### Changed
- Migrated to async processing
- Improved ICA component selection
- Optimized performance for real-time use

### Fixed
- Memory leak in batch processing
- WebSocket connection stability
- Edge cases in artifact detection

## [1.0.0] - 2023-06-01

### Added
- Initial release
- Basic artifact removal
- ICA implementation
- Command-line interface
